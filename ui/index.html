ClipOCR

Screen text → clipboard. On-device OCR, no history.

Updates

Automatic update checks are off. No update request is made unless you choose Check for updates.

When enabled, ClipOCR contacts github.com to ask for the latest version. GitHub sees your IP address. The request carries no version, platform or install identifier. No screenshots, OCR text or clipboard contents are sent. You can turn this off at any time.

Pixels never touch the clipboard. Copied text inherits OS clipboard syncing and clipboard-manager history. ClipOCR stores no OCR history.
