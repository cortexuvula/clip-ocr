Screen text → clipboard. On-device OCR, no history.

Updates

When automatic checks are on, ClipOCR contacts github.com once a day to look for a new version. GitHub can see your IP address. The check does not send your app version, platform, an installation identifier, screenshots, recognized text or clipboard contents. Turning this off stops automatic checks. “Check for updates now” makes one request even when automatic checks are off.

Pixels never touch the clipboard. Copied text inherits OS clipboard syncing and clipboard-manager history. ClipOCR stores no OCR history.
